(2U) Korteste vej i binær matrix

Koden i filen shortestPathBFS.js

  • Funktionen shortestPathBFS() har tre datastrukturer, hvor den ene (Queue) har vi selv implementeret.
  • Variablen visitedSet er et Set der gemmer alle de felter der allerede er besøgt.
    • Hvordan indsætter man noget i et Set og hvordan tjekker man om noget er i sættet?
    • MDN reference - Set
  • Varablen prevMap er et Map der for hvert felt gemmer det felt som det kom fra.
    • Hvordan indsætter man noget i et Map og hvordan får man værdien til en bestemt nøgle?
    • MDN reference - Map
  • Vi kan bruge key()-metoden i BinaryMatrixGraph-klassen når vi skal indsætte knuderne i datastrukturerne.
    • Hvad skal vi skrive for at indsætte startknuden i visitedSet?
