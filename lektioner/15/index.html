Markdown

  • Man kan nemt indsætte billeder i Markdown ved det normale ctrl+v.
  • Man kan indsætte formatteret kode på en linje (inline code) ved at sætte backticks (``) omkring, fx.
    `tower.shoot()` => tower.shoot()
  • Man kan indsætte en formatteret kode-blok ved at sætte den mellem to linjer med tre backticks:

      ```
  let x = 1;
  x += 3;
  ```
