Lav en intentionel merge-konflikt

  1. På GitHub: Tilføj følgende linje i README.md Hello mom og commit.
  2. I VS Code: Kør git pull.
  3. I VS Code: Lav linjen om til Hello mum and dad og kør git commit -m "edit: add 'dad' to hello message in readme" men kør IKKE git push.
  4. På Github: Slet linjen Hello mum og skriv Hello family i stedet og commit.
  5. I VS Code: Kør git pull. Der burde ske en merge konflikt.
  6. I VS Code: Løs merge-konflikten ved at vælge den version som du vil beholde.

(2U) Git Branches

Hvordan skal man branche?

  • Lav en ny branch hver gang du arbejder på en ny feature til dit program.
  • Brug korte, beskrivende navne med bindestreger og små bogstaver, fx. branch-navn.

Workflow

  • Lav altid en ny branch fra main: Kør git switch main først, ellers arver din nye branch ændringer fra den gamle.
  • Hold branches små og afgrænsede: Én feature pr. branch, og lav mange små commits undervejs.
  • Undgå generelt at arbejde i main-branchen. Main skal kun bruges når man merger en branch ind i den.
  • Når man er sikker på at alt fungerer merger man feature-branchen ind i main.

Samarbejde over GitHub

  • Pull de seneste ændringer (git pull) fra main, før du merger - så undgår du flest merge-konflikter.
  • Push din feature-branch til GitHub (git push -u origin branch-navn) - også mens du stadig arbejder på den, så dit arbejde er i sikkerhed.
  • Hvis man samarbejder med andre laver man en pull request som andre kan reviewe før branchen merges ind i main.

(2Ø) Fork, clone og branch et projekt

Fork og clone repo fra GitHub

  1. Gå ind på følgende GitHub repository:
    https://github.com/AHSarantaris/sunrise-game/
  2. Følg denne guide for at forke repository'et og clone det til jeres computer:
    https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo

Lav en feature-branch

  1. Lav en ny branch: git switch -c deflating-sun
  2. Få solen til at punktere når man klikker på den, og først derefter skal den falde ned:
    • Stop solen: Gør hastigheden til 0. Commit når det fungerer.
    • Sæt et flag der angiver at solen punkterer: sun.isDeflating = true. Commit når det fungerer.
    • Gør diameteren mindre med en konstant hastighed når det flag er sandt. Commit når det fungerer.
    • Stop når diameteren blive mindre end en bestemt værdi, prøv 40 pixel. Commit når det fungerer.
  3. På et hvilket somhelst tidspunkt efter det første commit i branchen pusher I til GitHub: git push -u origin deflating-sun.
  4. Når alt fungerer så merge jeres branch ind i main igen: git switch main og så git merge deflating-sun.
