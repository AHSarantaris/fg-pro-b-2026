(2U) Supplerende stof og Omfang

2.3 Supplerende stof

  • Det supplerende stof skal opfattes som fordybelsesområder, der ligger i forlængelse af den øvrige undervisning.
  • Eksempelvis kan nævnes programmering af en mobilapp, et spil, en webapplikation, en robot, en databaseapplikation eller et Internet of Things produkt.
  • Dele af det supplerende stof vælges i samarbejde med eleverne, når det er muligt.
  • Fagligt samspil med de øvrige fag i uddannelsen:
    • Matematik: Lineære funktioner og vektorer (Afleveringsprojekt 2).
    • Fysik: Bevægelse og tyngdekraft (mm.)
    • Biologi: Flokadfærd (Afleveringsprojekt 3).
    • Kommunikation & IT og teknikfag (DDU): Udvikling af hjemmesider (til næste år).
  • Der skal indgå læsning af it-faglige tekster på engelsk.
  • En anden mulighed er at gå i dybden med mere avancerede konstruktioner i det valgte programmeringssprog.

2.4 Omfang

  • "Det forventede omfang af fagligt stof er normalt svarende til 200 - 350 sider"
    • netbaserede tutorials (herunder video-tutorials),
    • netbaserede udviklingsværktøjer
    • biblioteksmoduler

    • i- og e-bøger
    • fysiske bøger
    • udleveret tekst materiale

(3U) Git-kommandoer der bruges hver dag i én branch

  • git status – se hvilke filer der er ændret
  • git add -A – stage alle ændringer
  • git commit -m "Beskriv ændringen" – gem en version (snapshot)
  • git push – send dine ændringer op til GitHub
  • git pull – hent ændringer fra GitHub
  • git log – se tidligere commits

(3Ø) Opstart af Git

Installer Git:

  • Download den nyeste version herfra:
    https://git-scm.com/

Konfigurer Git

  • Åben en terminal i VS Code.
  • Konfigurer Git med jeres navn:
    Kør git config --global user.name "Jeres Navn" hvor I indsætter jeres eget navn så man kan se hvilke commits I har lavet.
  • Konfigurer git med en email addresse:
    Kør git config --global user.email "jeres@email.dk" hvor I indsætter jeres personlige email-addresse.

Initialisér et repository

  1. Åben mappen i VS Code hvor jeres spil med solanimationen ligger. Omdøb den hvis der er mellemrum i mappens navn.
  2. Åben en terminal og tjek at stien er korrekt
  3. Kør git init for at initialisere versionskontrol med git i mappen.
  4. Der laves en skjult .git-mappe der opdateres hver gang der køres en kommando med git så den indeholder alt information om versionerne
  5. Opret en README.md fil i mappen, og skriv Hello World i den.
  6. Kør git add -A for at "stage" jeres ændringer.
  7. Kør git commit -m "First commit: Add readme".

(3Ø) Opstart af Github

1: Lav en github account

  • Brugernavn: Helst små bogstaver. Eventuelt jeres fornavn og efternavn med små bogstaver og uden mellemrum, eller initialer af enten fornavn+mellemnavn eller efternavn.
  • Email: Brug den samme personlige email-addresse som i Git.

Gør GitHub til remote

  1. Lav et public repo i Github der hedder “sunrise-game”. Jeres lokale repo behøver ikke at hedde det samme.
  2. Gå tilbage til VS Code terminalen og kør git remote add origin https://github.com/brugernavn/sunrise-game.git hvor I indsætter jeres GitHub brugernavn i url-addressen.
  3. Kør git push -u origin main for at pushe jeres lokale main-branch til origin/main på GitHub, og samtidig sætte origin/main som upstream-branch for jeres lokale main.

Lav en intentionel merge-konflikt

  1. På GitHub: Tilføj følgende linje i README.md Hello mom og commit.
  2. I VS Code: Kør git pull.
  3. I VS Code: Lav linjen om til Hello mum and dad og kør git commit -m "edit: add 'dad' to hello message in readme" men kør IKKE git push.
  4. På Github: Slet linjen Hello mum og skriv Hello family i stedet og commit.
  5. I VS Code: Kør git pull. Der burde ske en merge konflikt.
  6. I VS Code: Løs merge-konflikten ved at vælge den version som du vil beholde.
